# Security policy

## Supported versions

Security fixes are prioritized for the default branch and the latest released
version of each project. Older branches may not receive fixes; check the
target repository's release notes for its exact support window.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, pull
request, or discussion. Use [GitHub private vulnerability reporting](https://github.com/HesWidgetsGallery/.github/security/advisories/new)
when it is available for the affected repository. If it is unavailable, contact
the repository maintainers privately through their verified GitHub profile and
include `SECURITY` in the subject.

Include, if possible:

- affected repository, version, commit, or build;
- a concise description of the impact;
- reproduction steps or a minimal proof of concept;
- affected platforms, Qt versions, and compiler versions;
- any suggested mitigation.

We will acknowledge a report as soon as practical, investigate it privately,
and coordinate a fix and disclosure timeline with the reporter. Please avoid
including personal data or production secrets in a report.
