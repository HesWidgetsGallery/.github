# Support

For usage questions and development help:

1. Read the target repository's README and documentation first.
2. Search existing issues and discussions.
3. Ask a focused question with a minimal example, expected behavior, actual
   behavior, Qt/compiler versions, operating system, and relevant logs.

Use an issue only when the report describes a reproducible bug or a concrete
feature proposal. Do not use public issues for security reports; follow the
[security policy](SECURITY.md) instead.

Support is provided by maintainers and contributors on a best-effort basis.
There is no guaranteed response time or compatibility promise beyond what the
target repository documents.
