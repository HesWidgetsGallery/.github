# HesWidgetsGallery

![Qt](https://img.shields.io/badge/Qt-6%2B-41CD52?logo=qt&logoColor=white)
![C%2B%2B](https://img.shields.io/badge/C%2B%2B-17%2B-00599C?logo=c%2B%2B&logoColor=white)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-5C6BC0)

HesWidgetsGallery is a community of Qt developers building polished,
accessible, and reusable desktop UI components inspired by Fluent Design.
We care about native Qt integration, predictable APIs, visual consistency, and
documentation that helps people ship real applications.

HesWidgetsGallery 是一个专注于 Qt 桌面应用的开源组织，致力于构建现代、
可访问、可复用的 Fluent 风格控件与工具。我们重视原生 Qt 集成、稳定清晰的
API、一致的视觉体验，以及能够帮助开发者快速落地的文档。

## Projects

| Project | Description |

## Getting started

1. Open a repository above and read its README and build instructions.
2. Check the repository's supported Qt/compiler matrix before opening an issue.
3. For a local build, initialize any documented submodules first:

   ```bash
   git submodule update --init --recursive
   ```

4. Build and run the tests using the commands documented by that repository.

For the internal gallery project, start with its repository README and
documentation index. Members of the organization can access the private
repository directly from the organization page.
